# Examen Loghin Daniel

## Descriere proiect
Acest proiect a fost realizat pentru examenul de Git și GitHub.  
Scopul este să demonstreze utilizarea comenzilor Git pentru gestionarea unui repository, lucrul cu ramuri și fișiere.

## Pași realizați
1. Creat un nou repository pe GitHub, numit **ExamenLoghin_Daniel**.
2. Clonat repository-ul pe calculatorul local.
3. Adăugat fișierul `README.md` cu descrierea proiectului și numărul biletului.
4. Adăugat fișierul `.gitignore` pentru a ignora toate fișierele cu extensia `.exe`.
5. Creat o ramură nouă numită **development**.
6. Adăugat două fișiere HTML în directorul principal: `index.html` și `about.html`.
7. Împins modificările pe ramura **development** pe GitHub.
8. Concatentat ramura **development** cu ramura principală **main** folosind Git CLI.
